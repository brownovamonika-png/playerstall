Model type specification

Match Jason’s current production Everything on this form must align with Jason’s current production standards. Do not introduce improvements or alternate builds—customers must not receive two different variations of the same product, which would be confusing and inconsistent with what they were sold. That includes screws, hardware, and any other detail that would differ from what he has already done (same parts, same methods—nothing substituted or “upgraded” unless Jason’s spec explicitly calls for it).

One form — Jason has two model rows (Model X, Model Z) and Vu has three (Model X, Model Z, Model S). Each model row has four reference photos plus two lines of the same fields as the cushion sheet (color code, HS Code, quantity, width, depth, height — locker dimensions in inches), then two front panels per locker (one vented, one non-vented; each packed separately), then a lock box row matching the front-panel layout (heading, qty + image on one row; pre-drilled holes for a digital lock; lock supplied separately in Canada; packing notes below with a reference photo). Under each locker type there is a Notes / instructions box for anything extra. Print / PDF is a two-page summary: page 1 — job header plus Jason department and notes for each Jason locker row; page 2 — one compact table of every locker row (Jason and Vu) with colors, both dimension lines, vented / non-vented fronts, and lock box qty (reference photos stay on screen only). Cushions are on a separate cushion spec page (dimensions in cm, not inches). Open from disk or, with npm run dev, at /locker-line-spec-jason-vu-cushions.html (full URL: http://localhost:4321/locker-line-spec-jason-vu-cushions.html). The model rows under each department heading are inserted by JavaScript; if those areas stay empty, use a normal browser tab with scripts enabled (some editor or preview panes do not run the script, so the form will not appear). Use Print to save a PDF. Photos stay in your browser until you print; nothing is uploaded.

Locker models: All dimensions are in inches.
